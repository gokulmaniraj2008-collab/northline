A note on “open”

Code is only
one layer.

This directory focuses on companies whose main developer-facing AI product has source code available under an open-source license. Model availability and licensing are separate questions: a company can publish software openly while individual model weights carry their own terms.

Licenses shown here are for the linked repositories. Always review the current license and any model-specific terms before shipping.
